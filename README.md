Sistema de Irrigação Automática com Arduino

Objetivo
- Automatizar a irrigação de uma planta utilizando a umidade do solo para controlar a bomba de água.

Tecnologias

- Arduino
- Sensor de umidade
- Sensor de temperatura
- Módulo relé
- Bomba de água
- LEDs

Aprendizados
- Prática de lógica de programação, utilização do Arduino, sensores e componentes eletrônicos, além de resolução de problemas.
